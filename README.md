# 🐱 CYF ITD Cats

A responsive static website dedicated to cats, created as part of the **Code Your Future (CYF) - Intro to Digital** course.

🌐 **Live Demo:** [https://mixeys.github.io/cyf-itd-cats/](https://mixeys.github.io/cyf-itd-cats/)

---

## 📌 Project Overview

This project is a fundamental web development assignment focused on building a clean, semantic web page using **HTML5** and **CSS3**. It highlights fun facts about cats, interesting information, and an image gallery with a mobile-friendly responsive layout.

## 🛠️ Technologies Used

- **HTML5** — Semantic page structure
- **CSS3** — Custom styling, Flexbox layout, and responsive media queries
- **GitHub Pages** — Project hosting and deployment

## 📁 Project Structure

```text
cyf-itd-cats/
├── index.html   # Main HTML markup
├── style.css    # Page styles and responsive layout
├── README.md    # Project documentation
└── .gitignore   # Git ignore rules
```

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Mixeys/cyf-itd-cats.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd cyf-itd-cats
   ```
3. **Open `index.html`** directly in any web browser.

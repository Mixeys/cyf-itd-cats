# CYF ITD Cats

A simple HTML & CSS website about cats created as part of the Code Your Future (CYF) Intro to Digital course.

## Overview

This project showcases basic HTML structure and CSS styling to present fun facts and information about cats.

## Project Structure

- `dist/index.html` - Main HTML page
- `dist/style.css` - CSS stylesheet

## How to View Locally

Open `dist/index.html` directly in any web browser.
